# Moots: 2nd Year Moot Court Cases - Department of Laws, Chandigarh

[![GitHub Repository](https://img.shields.io/badge/GitHub-Repository-blue?style=flat-square&logo=github)](https://github.com/Rv-09/Moots)

## Description

This repository compiles moot court cases specifically tailored for 2nd-year students of the Department of Laws, Chandigarh. It serves as a central hub for accessing and referencing previous moot problems, providing valuable resources for practice and preparation.

## Features and Functionality

*   **Centralized Resource:** Provides a single location for 2nd-year moot court problems.
*   **Case Archives:** Allows students to access and analyze past moot problems to understand the types of legal issues typically covered.
*   **Downloadable Resources:** Facilitates easy access to the moot court problems for offline study and preparation.

## Technology Stack

*   This repository primarily uses **Markdown (.md)** for documentation.
*   Files are stored in a structured directory format within the GitHub repository.

## Prerequisites

No specific software installation is required. A web browser is sufficient to access and download the files directly from the GitHub repository. A Markdown editor can be helpful for contributing to the documentation.

## Installation Instructions

No installation is required to use this repository. Simply navigate to the repository URL: [https://github.com/Rv-09/Moots](https://github.com/Rv-09/Moots) in your web browser.

To contribute, you'll need a GitHub account and Git installed on your local machine.

1.  **Fork the repository:** Click the "Fork" button on the top right of the repository page.
2.  **Clone the forked repository:**
    ```bash
    git clone https://github.com/<your_username>/Moots.git
    cd Moots
    ```
3.  **Create a branch for your contributions:**
    ```bash
    git checkout -b feature/your-feature-name
    ```

## Usage Guide

1.  **Browse the Repository:** Navigate through the repository's file structure to locate specific moot court problems.
2.  **Download Cases:** Click on the file name to view or download the moot court case problem in the appropriate format (e.g., PDF, Word document, Markdown).
3.  **Contribute Cases:** Follow the contributing guidelines to add new moot court cases or update existing ones.

## API Documentation

This repository does not expose any APIs. It is a static collection of files.

## Contributing Guidelines

We welcome contributions to improve the repository and expand the collection of moot court cases. Please follow these guidelines:

1.  **Adding New Cases:**
    *   Create a new directory for each moot court case, named descriptively (e.g., "Moot_Problem_Company_Law_2023").
    *   Include the moot court problem statement in a clear and readable format (preferably PDF or Markdown).
    *   If available, include the rules of the moot court competition in the same directory.
    *   Place the directory in appropriate year order within the main directory.
2.  **Updating Existing Cases:**
    *   If you find any errors or have updated versions of existing cases, please create a pull request with the corrected files.
3.  **Pull Requests:**
    *   Ensure your code is well-formatted and follows the existing file structure.
    *   Provide a clear and concise description of your changes in the pull request.
    *   Adhere to the repository's existing style and formatting conventions.

Example commit message:
`feat: Add Moot Problem on Environmental Law (2022)`
